# 第1關《封印的門扉》遊戲畫面美術工程收尾紀錄

日期：2026-10-27

## 結案範圍

- 第1關入口場景已改用石砌拱門與木製雙扇大門，三道封印依序配置於左門環、中央門縫與右門環。
- 遊戲畫面由上而下依序呈現關卡名稱、當前封印提示、重播按鈕、大門與封印、符文卡片及答題區。
- 符文卡片與答題欄會依每題實際卡片數量水平置中，不再以固定四欄造成偏移。
- 每題答對時，答對音效、答題框亮藍閃光與藍色光點飛向當前封印會同步開始；850 毫秒動畫完成後才解鎖封印並播放下一題音訊。
- 最後一題會先完整呈現第三道封印解鎖，再結束關卡；暫停與系統減少動態效果設定均已納入動畫時序。
- 第8關仍保留原有魔法門場景與版面，未受第1關專用美術影響。

## 素材與程式整理

- 正式素材統一為 `public/assets/images/campaign/level-01-gate.png`，尺寸 768×307、檔案 207,912 bytes；原始 1116×446 概念圖未複製進正式包體。
- 大門、封印與動畫直接由正式 `SequenceLockGame` 使用；預覽頁沒有另存一套只供測試的美術邏輯。
- 保留 `?preview=sequence-lock-gate` 開發預覽，供日後檢查不同題目卡片數量、答錯回復、三道封印與答對動畫。
- 預覽入口受 `VITE_ENABLE_PREVIEWS` 或開發模式保護，不會在一般正式建置中啟用。
- 新增素材尺寸與 250 KiB 上限測試，避免日後替換時意外把高解析原圖重新帶入正式包體。

## 後續維護界線

本階段只結案第1關《封印的門扉》的遊戲畫面美術與答對回饋動畫。第8關雖共用順序鎖玩法，但保留獨立的魔法門場景；若後續調整第8關美術，不應直接覆寫第1關專用大門、封印配置或動畫節奏。
