# 第一章第5關迷霧哨兵戰鬥美術工程收尾

收尾日期：2026-11-12

## 正式整合範圍

- 第5關《迷霧哨兵》沿用第4關森林小徑背景；左側顯示玩家正式頭像組成的冒險者紙偶，右側顯示一般或盾牌迷霧士兵。
- 戰鬥角色在 iPadOS Safari、Android 與電腦瀏覽器均使用明確尺寸與版面配置；單一及雙敵人波次維持相同士兵尺寸，不會超出戰鬥場景。
- 玩家／敵人回合提示移至戰鬥場景下方，分別對齊冒險者與敵方位置。
- 迷霧士兵生命圖示使用 50% 白色半透明底框；敵方圖片水平鏡像，方向朝向冒險者。
- 每波新敵人以 `600ms` 淡入，不影響題目播放與操作鎖定時序。

## 技能與攻防回饋

- 「符音穿透」與「回音護盾（被動技能）」使用正式圖示；能量需求以三枚藍色能量球表示。
- 技能可用時使用橘色底；不可用時採灰暗底色與文字色，保留清楚的不可操作辨識。
- 玩家答對時，冒險者向右出擊、藍色劍痕由右上往左下揭露，接著敵人快速震動。
- 玩家答錯時，敵人向左出擊、灰色劍痕疊加在冒險者上，接著冒險者快速震動；戰鬥場景本身不再整體震動或發出紅光。
- 敵人回合答對時顯示防禦成功特效；回音護盾觸發時顯示護盾圖案。兩者最高不透明度為 70%，並在劍痕結束後延長約 `500ms` 消失。
- 「符音穿透」使用弧形技能劍痕，沿圖案曲線由上端向下揭露。
- 劍痕採固定尺寸遮罩揭露，約 `200ms` 完成、停留約 `200ms` 後直接消失；不使用縮放進場。

## 開發與回歸入口

- 保留 `?preview=zhuyin-battle` 完整玩法預覽，僅在開發環境或明確啟用 `VITE_ENABLE_PREVIEWS` 時可用。
- 預覽可切換正式帳號頭像或訪客預設頭像，並可重複測試五波敵人、能量按鈕與完整攻防動畫。
- 永久開發工具 `tools/hair-calibrator/` 不屬於本次清理範圍，完整保留。

## 已知裝置差異

- 舊款 iPad Air 2 的 Safari 偶爾會在直線劍痕遮罩開始前短暫顯示劍痕末端；Android、電腦與弧形「符音穿透」未重現。
- 曾試作延遲兩個畫面影格、平切遮罩端點及加大起始位移，但實機仍偶發，因此依使用者決定回復穩定版本，不保留該補丁。
- 此差異不影響操作、傷害判定或回合流程；若未來更多裝置重現，再另案評估非 SVG 的 CSS 裁切版本。
