# 小小注音冒險家 v3

這是從原始 v2.1 單檔 PWA 重建的正式模組化版本。`原始程式框架/` 保留為唯讀參考，不應直接修改。

## 開發指令

```bash
npm install
npm run dev
npm test
npm run build
npm run preview
```

正式建置輸出位於 `dist/`。

圖片逐張尺寸、格式與檔案大小目標請參考 [`docs/IMAGE_ASSET_GUIDE.md`](docs/IMAGE_ASSET_GUIDE.md)。

## 已完成階段

- Vite、React、TypeScript 與 PWA 建置架構。
- 一般模式：新手、專家、菁英三種難度。
- 無限模式：生命、Combo、選項與倒數時間階梯。
- 洗牌袋題庫，一輪 37 個注音內不重複。
- 錯誤字卡立即停用，避免連點重複扣血。
- 使用截止時間計算的倒數計時，切到背景時暫停。
- IndexedDB 冒險紀錄資料庫。
- 新手、專家、菁英、無限四個獨立排行榜分頁。
- PWA 更新只在非遊戲狀態提示，不會強制中斷遊戲。
- 音訊拆成獨立 MP3 資源，不再載入大型 Base64 JavaScript。
- 短音效與注音發音使用 Web Audio 解碼快取；目前題目所需聲音優先處理，避免背景下載阻塞操作。
- 使用者按下「開始冒險」後會檢查資源版本及完整音訊快取；只有首次安裝、資源版本更新或快取缺檔時，才顯示單一進度畫面並準備全部圖片與注音。
- 主程式與圖片由 Service Worker 版本化預快取；41 個 MP3 完成獨立音訊快取後可離線遊玩。同一資源版本再次啟動會直接進入帳號選擇，並在選單操作期間從本機快取靜默解碼音訊。
- 每個主要畫面都有獨立瀏覽紀錄；遊戲放棄確認取消後會回復既有保護紀錄，不在返回事件內動態新增紀錄；PWA 歡迎頁返回則直接離開。
- PWA 優先鎖定直式，未支援螢幕鎖定的觸控瀏覽器會顯示轉向提示。
- iOS／iPadOS 獨立 PWA 使用穩定視窗高度鋪滿安全區，互動內容仍避開 Home Indicator。
- 核心計分、星級、難度、時間與題庫單元測試。
- 教學導向干擾選項：字音與字形混淆分開維護，難度越高越優先出現易混淆符號。
- 本機玩家帳號：永久 UUID、PBKDF2-SHA-256 密碼門鎖及不保存明碼的驗證資料。
- 帳號名稱在同一裝置不可重複；帳號資料與四個排行榜依玩家 UUID 隔離。
- 訪客工作階段與排行榜只存在記憶體，返回帳號選擇或重新啟動後清除。
- 玩家驗證與資料庫分層，預留未來切換伺服器登入及跨裝置同步。
- 帳號名稱支援中英文、數字、可見特殊符號與 Emoji；同名比對會統一大小寫、全形字及空格，但保留原顯示形式。
- 整台裝置共用 6 位數家長 PIN；新增帳號、忘記密碼與帳號管理須經家長授權。
- 家長 PIN 與一次性復原碼只保存 PBKDF2-SHA-256 雜湊；連續錯誤 5 次會鎖定 30 秒。
- 家長管理可在再次驗證目前 PIN 後變更為新的 6 位數 PIN；原家長復原碼保持不變。
- 忘記使用者密碼可由家長 PIN 授權重設，不影響頭像、成績或其他學習資料。
- 帳號刪除採 7 天等待期，期間可由家長管理恢復；期滿後才清除帳號與全部成績。
- 帳號建立、登入、家長驗證、復原與密碼重設採單一頁面歷史紀錄；完成確認不再重複堆疊來源頁，返回一次即可回到正確上一層。
- 分層式 SVG 捏臉系統：8 種正式臉型以可換膚色的 mask 與透明 details 疊合，並可自由搭配膚色、髮型、髮色、眉毛、眼睛、鼻子、嘴巴、臉頰、眼鏡及髮飾。
- 頭像以輕量配方保存在玩家資料中；舊版種子頭像會穩定轉換成新版配方，舊有方圓臉資料會自動對應到新版方臉。
- 建立帳號前先完成頭像，返回帳號資料時會保留已輸入內容；登入後可直接點擊模式頁左上角頭像再次編輯。

## 干擾選項策略

- 新手：優先使用差異較大的選項，先建立辨識成功經驗。
- 專家：一般選項與易混淆選項混合。
- 菁英：優先加入聲音或字形易混淆的符號。
- 無限：第 1–10 題採新手策略，第 11–30 題混合，第 31 題後優先易混淆。

未來可接上各帳號的誤答配對紀錄，將固定策略升級成個人化權重。

## GitHub Pages 發布

`main` 分支保存完整原始碼。推送後，GitHub Actions 會依序安裝、測試、建置，並只將 `dist/` 成品發布到 GitHub Pages。Vite 使用相對基底路徑，以支援 GitHub 專案頁面、一般網域與日後 Capacitor 封裝。

## 資料原則

- v3 使用全新資料庫，不讀取或遷移 v2 的 `localStorage` 排行榜。
- 正式玩家使用永久 UUID，所有結果依玩家隔離。
- 訪客模式將只存在記憶體，不寫入 IndexedDB。
- IndexedDB v3 新增家長安全設定；既有 v3.1 玩家檔案與成績原地保留。

### 未來玩法：拼音練習

除了目前的「播放一個注音符號，選出對應字卡」，未來新增由多個注音符號及聲調組成的拼音練習。正式設計時至少要分開處理：

- 聲母、介音、韻母的組合與合法音節資料。
- 一聲、二聲、三聲、四聲及輕聲的辨識與標示位置。
- 聽音選拼音、依序組合拼音、看拼音選聲音等不同題型。
- 由二拼到三拼、由無聲調干擾到相近聲調干擾的漸進難度。
- 每位玩家的音節與聲調錯誤紀錄，供日後複習及個人化出題使用。

此項目前只列入工程路線圖；題庫範圍、語音素材、計分、計時及解鎖順序須在實作前另行確認。
