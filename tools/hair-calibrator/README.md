# 頭像圖層手動調校工具

這是專案永久保留、可重複使用的開發工具。後續髮型及其他頭像項目仍可能使用，請勿在清理素材、隔離區或中間產物時刪除。

目前入口：`tools/hair-calibrator/index.html`

目前狀態：本階段髮型調校已完成。頭像編輯頁第 1～5、7、8 款已採用最終調校數據；第 6 款依決定保留原校準值。工具目前載入第 8 款（畫面順位 8、正式素材 ID `11`）的已驗收最終數據，並沿用其獨立 localStorage 儲存鍵。

髮型素材統一引用 `public/assets/avatar-parts/hair/approved/` 的正式檔案；工具目錄不保留重複素材副本。

功能包括：

- 以固定 512×512 座標調整圖層位置。
- 滑鼠拖曳及鍵盤方向鍵微調。
- 水平與垂直縮放。
- 按臉型分別確認並保存草稿。
- 匯出可供程式套用的 JSON 校準資料。
- 目前第 8 款的六臉型最終數據作為工具預設值；預設版本更新時會重新載入已驗收數據，之後重新整理仍保留手動進度。

每個待調校項目必須使用獨立的 `localStorage` 儲存鍵及 JSON 檔名，避免覆蓋先前資料。
