# 頭像圖層手動調校工具

這是專案永久保留、可重複使用的開發工具。後續髮型及其他頭像項目仍可能使用，請勿在清理素材、隔離區或中間產物時刪除。

目前入口：`tools/hair-calibrator/index.html`

目前調校項目：新髮型候選素材 08（`hair-candidate-08.svg`）。新髮型 01、02、03、04、05、06、07 的獨立 localStorage 資料與素材仍保留。

功能包括：

- 以固定 512×512 座標調整圖層位置。
- 滑鼠拖曳及鍵盤方向鍵微調。
- 水平與垂直縮放。
- 按臉型分別確認並保存草稿。
- 匯出可供程式套用的 JSON 校準資料。
- 髮型 11 目前以 `hair-11-face-calibration(2).json` 的六臉型數據作為新一輪微調預設值；預設值只初始化一次，後續重新整理仍保留手動進度。

每個待調校項目必須使用獨立的 `localStorage` 儲存鍵及 JSON 檔名，避免覆蓋先前資料。
