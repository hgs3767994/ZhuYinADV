# 眼型手動縮放調校工具

入口：`tools/eye-calibrator/index.html`

- 固定使用臉型 1（圓臉）作為共同調校基準。
- 允許水平縮放、垂直縮放及左右對稱的眼距調整；整組眼型中心與垂直位置不可移動。
- 每款眼型使用獨立 `localStorage` 鍵。
- 可載入先前匯出的 JSON，經完整性與數值範圍檢查後更新各眼型的獨立儲存資料。
- 匯出的縮放比例共同套用到所有臉型。
- 可匯出 `eye-face-calibration.json`。
- `generate-split-assets.mjs` 會從每款完整眼型產生真正只含單眼的左右純向量素材，眼距調整不得改回複製完整雙眼再以外層遮罩裁切。
